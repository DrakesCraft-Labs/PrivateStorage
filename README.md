# PrivateStorage almacenamiento privado

PrivateStorage es un Slimefun4 Complementos accesorios.
necesitas instalar Slimefun4 para permitir que este complemento se ejecute.

Este archivo adjunto agrega dos nuevos tipos de cofres: Privados(seguro)con publico(caja)。Las cajas fuertes solo pueden ser abiertas o destruidas por el jugador que colocó el cofre, mientras que los cofres públicos siguen las reglas para proteger complementos.

Este archivo adjunto agrega cajas de diferentes tipos de madera, cajas de hierro, cajas doradas, cajas de diamantes, cajas a prueba de explosiones, etc.。
